# @dialecte/core API index

Generated from the source by `dialecte skills generate`: every public method of the project, document, query and
transaction, then, one section per entry (`@dialecte/core/utils`, `@dialecte/core/test`, ...), the functions its
exports add, each with the first paragraph of its JSDoc and its `@intent` tags. It is the same in the repository
and in the installed package, and `npm run skills:check` keeps it fresh.

Look up your need in the first table (what you are trying to do), then read the method's row. When a
method looks close to your need, read its JSDoc and its tests before ruling it out, and name what you
ruled out and why in your hand-over.
