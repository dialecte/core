### Changed

- **Breaking:** the `commit` message of a Project's channel (`ProjectChannelMessage`) carries a required `changes`: `CommitChanges` (`created`, `updated`, `deleted`, each a list of `ChangedRecord` = `{ id, tagName, parentId }`), or `{ unknown: true }` (`UnknownCommitChanges`: read again). A Document's commit (`transaction`, `prepare().commit()`) tells every record it wrote, `beforeCommit` hook writes included: `created` and `updated` with the parent after the write, `deleted` with the parent it had; a record moved under another parent is in `updated` with both parents. Past 5,000 refs in one commit, for a commit refused with its connection lost that may have landed, for an undo, a redo and every change a store announces (another connection's commit, a bulk write), `changes` is `{ unknown: true }`. A listener patching a view from `changes` handles both forms; code building a `commit` message (a test, a custom store's announcement) adds `changes`. `ChangedRecord`, `CommitChanges` and `UnknownCommitChanges` are exported. A message at the cap is about 570 KB as JSON (structured clone ~1.3 ms in Chromium); one past it about 120 bytes.
- `STORAGE_KINDS_VERSION` is 10, the SQLite hub protocol 10 and the engine wire protocol 6: the shared shapes carry the new message, so a copy of the library at an older version finds no storage kind registered by this one (`PROJECT_STORAGE_NOT_REGISTERED`), and a realm or engine of another version is refused as before.
